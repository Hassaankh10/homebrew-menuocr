# MenuOCR Homebrew tap

```sh
brew tap Hassaankh10/menuocr
brew install --cask menuocr
```

Requires Apple Silicon and macOS 13 or later. Tesseract is installed automatically.

Enable Screen Recording for MenuOCR in System Settings, then reopen the app.

To update:

```sh
brew update
brew upgrade --cask menuocr
```
